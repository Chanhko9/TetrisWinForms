DUEL ARENA
- Match time: 5:00
- Highest score when time expires wins.
- Same scoring as the main game.
- Player 1: A/D move, W rotate, S soft drop, SPACE hard drop, C hold.
- Player 2: Left/Right move, Up rotate, Down soft drop, ENTER hard drop, RSHIFT hold.
- P pauses the entire match.
- If a player tops out, that player stops scoring while the other player can continue.
- If both players top out, the match ends immediately.

SCORING
- +1 base point per cleared row.
- Combo bonus = combo streak - 1.
- Back-to-Back Tetris bonus = +2.
- Move, rotate, soft drop and hard drop give no direct score.
